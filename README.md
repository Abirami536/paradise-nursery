
# Paradise Nursery Shopping Application

Welcome to Paradise Nursery!

Paradise Nursery is an online plant shop where customers can explore houseplants, view prices, add plants to a shopping cart, and manage their orders.

## Features
- Browse houseplants by category
- View plant names, images, and prices
- Add plants to the shopping cart
- Increase or decrease quantities
- Remove items from the cart
- Calculate the total price

## Technologies
- React
- JavaScript
- CSS
- Redux Toolkit

## Project Purpose
This project demonstrates the development of a dynamic and user-friendly online plant shopping application.
